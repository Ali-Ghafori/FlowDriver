# FlowDriverAIAI 🌊

> **بهینه‌شده برای ابزارهای AI خط فرمان** — FlowDriverAIAI نسخه ۱.۳.۲ به‌طور خاص برای تونل کردن ترافیک دستیارهای هوش مصنوعی (Claude Code، OpenCode، Cursor و دیگران) از طریق شبکه‌های محدود شده بهینه‌سازی شده است. این ابزار جلسات چندساعته پایدار با حداقل قطعی اتصال فراهم می‌کند و ابزارهای کدنویسی هوش مصنوعی را در مناطق فیلتر شده کاملاً قابل استفاده می‌سازد.

**FlowDriverAIAI** یک تونل TCP پنهان است که ترافیک شبکه را از طریق گوگل درایو هدایت می‌کند. به جای اتصال مستقیم TCP، داده‌ها در قالب فایل‌های باینری بسته‌بندی شده، در یک پوشه مشترک گوگل درایو آپلود می‌شوند و در طرف مقابل بازسازی می‌گردند — در نتیجه تمام ترافیک مانند استفاده عادی از API گوگل درایو به نظر می‌رسد.

## نحوه عملکرد

```
[برنامه شما] → SOCKS5 → [کلاینت FlowDriverAIAI] → گوگل درایو ← [سرور FlowDriverAIAI] → [سرور مقصد]
```

۱. **کلاینت** روی یک پورت SOCKS5 محلی گوش می‌دهد. وقتی برنامه شما متصل می‌شود، جریان TCP را در قالب فایل‌های باینری `.bin` بسته‌بندی کرده و در پوشه مشترک گوگل درایو آپلود می‌کند.

۲. **سرور** همان پوشه درایو را به‌طور مداوم بررسی می‌کند. وقتی فایل درخواست پیدا می‌کند، آن را دانلود کرده، یک اتصال TCP واقعی به مقصد برقرار می‌کند و پاسخ را به‌عنوان فایل دیگری آپلود می‌کند.

۳. هر دو طرف فایل‌ها را پس از خواندن حذف می‌کنند، و پوشه درایو را تمیز نگه می‌دارند.

این اتصال از نظر هر سیستم مانیتورینگ شبکه یا DPI مانند فعالیت عادی API گوگل درایو به نظر می‌رسد.

## تازه‌های نسخه ۱.۳.۲

- **رفع مشکل ابزارهای AI**: متد `VirtualConn.Write()` اکنون در صورت بسته بودن جلسه، خطای `net.ErrClosed` برمی‌گرداند. قبلاً کلاینت‌های HTTP/2 (مانند Claude Code و OpenCode) بی‌صدا به یک جلسه مرده می‌نوشتند و در خواندن بعدی EOF آنی دریافت می‌کردند که باعث خطای "socket connection closed unexpectedly" می‌شد.
- **رفع جلسات زامبی**: متد `handleServerConn` در سمت سرور اکنون به جای `RemoveSession` از `CloseSession` استفاده می‌کند. این کار یک پیام `Close=true` به کلاینت می‌فرستد تا اتصالات HTTP/2 به‌جای قطع بی‌صدا، یک EOF پاک دریافت کنند.
- **رفع مشابقه TOCTOU**: بررسی نشان‌گر بسته شدن و جستجوی نقشه جلسه اکنون به‌صورت اتمی تحت قفل `sessionMu` انجام می‌شود.
- **تلاش مجدد آپلود**: آپلودهای ناموفق تا ۳ بار با تاخیر نمایی مجدداً تلاش می‌شوند.
- **پشتیبانی از فایل لاگ**: پرچم جدید `-log <مسیر>` لاگ‌ها را در فایل می‌نویسد در حالی که به stdout هم چاپ می‌کند.
- **لاگ‌گذاری توکن OAuth2**: رویدادهای تجدید توکن اکنون با تایم‌استمپ ثبت می‌شوند.

## شروع سریع

آخرین باینری‌های آماده را از صفحه [Releases](../../releases) دانلود کنید.

### ۱. دریافت اعتبارنامه گوگل درایو

۱. به [کنسول گوگل کلاود](https://console.cloud.google.com/) بروید، یک پروژه بسازید و **Google Drive API** را فعال کنید.
۲. به بخش **APIs & Services → OAuth consent screen** بروید. نام برنامه و ایمیل پشتیبانی را پر کنید، سپس روی **Publish App** کلیک کنید (از انقضای توکن هر ۷ روز جلوگیری می‌کند).
۳. به بخش **Credentials → Create Credentials → OAuth client ID** بروید. نوع **Desktop App** را انتخاب کنید.
۴. فایل JSON را دانلود کرده و آن را با نام `credentials.json` ذخیره کنید.

### ۲. پیکربندی

**کلاینت** (`client_config.json`):
```json
{
  "listen_addr": "127.0.0.1:1080",
  "storage_type": "google",
  "refresh_rate_ms": 400,
  "flush_rate_ms": 800,
  "idle_timeout_sec": 900,
  "transport": {
    "TargetIP": "216.239.38.120:443",
    "SNI": "google.com",
    "HostHeader": "www.googleapis.com",
    "InsecureSkipVerify": false
  }
}
```

بلوک `transport` قابلیت **Domain Fronting** را فعال می‌کند — تمام ترافیک HTTPS از طریق IPهای گوگل هدایت می‌شود و مسدودسازی مبتنی بر IP را دور می‌زند. اگر پشت سانسور نیستید، این بلوک را حذف کنید.

`google_folder_id` را خالی بگذارید — ابزار در اولین اجرا به‌طور خودکار پوشه‌ای با نام **Flow-Data** پیدا کرده یا می‌سازد و شناسه آن را در کانفیگ شما ذخیره می‌کند.

**سرور** (`server_config.json`):
```json
{
  "storage_type": "google",
  "refresh_rate_ms": 400,
  "flush_rate_ms": 800,
  "idle_timeout_sec": 900
}
```

### ۳. احراز هویت اولیه (روی ماشین کلاینت)

یک بار کلاینت را به‌صورت تعاملی اجرا کنید تا دسترسی به گوگل درایو را مجاز کنید:

```bash
./client -c client_config.json -gc credentials.json
```

یک URL در ترمینال نمایش داده می‌شود. آن را در مرورگر باز کنید، وارد حساب گوگل خود شوید، دسترسی‌ها را تایید کنید، سپس URL کامل redirect را از نوار آدرس مرورگرتان کپی کرده و در ترمینال پیست کنید.

یک فایل `.token` در کنار `credentials.json` ساخته می‌شود. این فایل حاوی توکن تجدید شماست — هر دو فایل `credentials.json` و `.token` را به سرور منتقل کنید.

### ۴. اجرا

**سرور** (روی ماشین upstream شما):
```bash
./server -c server_config.json -gc credentials.json -log server.log
```

**کلاینت** (روی ماشین محلی شما):
```bash
./client -c client_config.json -gc credentials.json -log client.log
```

کلاینت روی آدرس `127.0.0.1:1080` گوش می‌دهد (SOCKS5). برنامه خود را به این آدرس هدایت کنید.

## استفاده با ابزارهای AI خط فرمان

### Claude Code
```bash
export HTTPS_PROXY=socks5://127.0.0.1:1080
claude
```

### OpenCode
```bash
export HTTPS_PROXY=socks5://127.0.0.1:1080
opencode
```

### با GOST (پل HTTP به SOCKS5)
اگر ابزار شما فقط از پراکسی HTTP پشتیبانی می‌کند، از [GOST](https://github.com/go-gost/gost) به‌عنوان پل استفاده کنید:
```bash
gost -L http://:8080 -F socks5://127.0.0.1:1080
```
سپس متغیر محیطی را تنظیم کنید: `HTTPS_PROXY=http://127.0.0.1:8080`

## عملکرد و سهمیه‌های API

گوگل درایو محدودیت‌های سفت‌وسختی برای درخواست‌های API دارد. پیکربندی پیشنهادی برای ترافیک AI API:

| تنظیم | پیشنهادی | توضیح |
|---|---|---|
| `refresh_rate_ms` | ۴۰۰ | فاصله polling برای دریافت داده |
| `flush_rate_ms` | ۸۰۰ | هر چند میلی‌ثانیه یک بار بافر TX آپلود می‌شود |
| `idle_timeout_sec` | ۹۰۰ | ۱۵ دقیقه — به اندازه کافی طولانی برای پاسخ‌های streaming AI |

- `refresh_rate_ms` را زیر ۱۰۰ms تنظیم نکنید — سهمیه روزانه خود را تمام خواهید کرد.
- سرور هنگامی که جلسه فعالی وجود ندارد، به‌طور خودکار فاصله polling را به ۵ ثانیه افزایش می‌دهد، که مصرف API را در حالت بیکار تقریباً به صفر می‌رساند.

## ساخت از سورس

```bash
git clone https://github.com/Ali-Ghafori/FlowDriverAI
cd FlowDriverAI
go build -ldflags "-X main.version=v1.3.2" -o client ./cmd/client
go build -ldflags "-X main.version=v1.3.2" -o server ./cmd/server
```

نیاز به Go 1.22 یا بالاتر دارد.

## پرچم‌های خط فرمان

```
-c    مسیر فایل کانفیگ              (پیش‌فرض: config.json)
-gc   مسیر credentials.json        (پیش‌فرض: credentials.json)
-log  مسیر فایل لاگ                 (پیش‌فرض: فقط stdout)
```
